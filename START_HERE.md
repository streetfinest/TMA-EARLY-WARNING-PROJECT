# Start Here

Open `notebooks/Seasonal_Climatology_Research.ipynb` in JupyterLab and run all cells in order.

## Windows (uv)

Run this command in PowerShell from the extracted project directory:

```powershell
uv run --with-requirements requirements.txt jupyter lab
```

In JupyterLab select the Python 3 kernel, open the notebook, then choose **Run → Run All Cells**.

All data required for the analysis is included. The notebook will regenerate forecasts, tables, metrics and figures under `outputs/`.
